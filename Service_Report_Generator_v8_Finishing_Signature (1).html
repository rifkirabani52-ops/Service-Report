Service Report Generator

Form pengisian berdasarkan template Customer Service Report Form PT. Surya Bali Makmur / D&V Medika.

Template PDF asli sudah ditanam di dalam file HTML ini. Setelah data diisi dan tanda tangan dibuat, tombol Generate PDF akan membuat PDF menggunakan template tersebut sebagai halaman dasar. Di iPhone/iPad, menu Bagikan akan dibuka agar PDF bisa langsung dikirim ke WhatsApp, Mail, Files, dan lainnya.
